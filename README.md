# MX 文件管理器

Windows 桌面应用 + 纯浏览器双形态的文件管理器,核心卖点:**点击任意常见格式的文件,主区域直接变成对应的查看器 / 编辑器 / 播放器**,无需安装任何外部程序。

![技术栈](https://img.shields.io/badge/React%2019-Electron-TypeScript-blue)

## 快速开始

### 桌面应用(推荐)

```bash
npm install
npm run app        # 构建并打包 NSIS 安装包(输出在 release/)
```

安装包为单文件一键安装,自动创建桌面快捷方式「MX文件管理器」。桌面版拥有**完整文件系统权限**:启动即列出所有磁盘与常用目录,任意路径直达,删除进回收站,无需任何授权。

### 浏览器版(零安装)

```bash
npm install
npm run dev        # 开发模式,默认 http://localhost:5173
```

> 浏览器版请使用 Edge / Chrome(本地读写依赖 File System Access API),点击「添加文件夹」授权目录;或用「演示模式」在内存中体验全部功能。

开发桌面版:`npm run electron:dev`(先起 vite),再另开终端 `npx electron .`。

## 桌面版 vs 浏览器版

| | 桌面版(Electron) | 浏览器版(Edge/Chrome) |
| --- | --- | --- |
| 文件访问 | 完整文件系统,免授权 | 需逐目录授权(句柄持久化) |
| 任意路径 | ✅ 面包屑直接输入 | ❌ 仅授权过的根 |
| 文件夹重命名/移动 | ✅ 原生瞬时 | 重建+迁移(大目录慢) |
| 删除 | ✅ 进回收站 | 永久删除 |
| 视频播放 | 流式协议,大文件零拷贝 | blob URL |
| 安装体积 | ~90 MB 安装包 | 零安装 |

两版共用同一套 UI 与全部查看器——差异全部被 `FSProvider` 接口隔离(`src/fs/electron.ts` vs `src/fs/fsa.ts`),运行时自动探测所在环境。

## 功能总览

### 文件管理
- 侧边栏:磁盘 / 桌面 / 下载 / 文档等常用目录,可添加任意文件夹为位置(桌面版走系统选择对话框)
- 多标签页、前进 / 后退 / 上一级、可编辑面包屑路径(桌面版可直接粘贴任意 Windows 路径)
- 详细列表 / 大图标两种视图,虚拟滚动(十万级文件、两万行文本不卡)
- 按名称 / 大小 / 类型 / 日期排序,实时搜索过滤,显示隐藏文件开关
- 新建文件夹 / 文件、重命名(F2)、删除(桌面版进回收站)、复制 / 剪切 / 粘贴(Ctrl+C/X/V)
- 拖拽移动到文件夹或面包屑(桌面版还可从资源管理器拖入文件导入)
- 同名冲突对话框(覆盖 / 跳过 / 保留两者)、撤销(Ctrl+Z)、操作进度条
- 空格键快速预览(QuickLook 式预览面板)、深色 / 浅色主题、设置与会话持久化

## 架构

```
UI 层   React 19 + Tailwind 4:标签页 / 文件区 / 预览面板 / 查看器
应用层  Zustand:文件系统状态 / 命令(撤销重做) / 快捷键 / 设置
服务层  FSProvider 接口 · 格式嗅探 · 缩略图缓存(LRU)
适配层  ElectronProvider(Node fs + 流式协议) · FsaProvider(浏览器) · MemoryProvider(演示)
```

所有 UI 只依赖 `src/fs/types.ts` 里的 `FSProvider` 接口。Electron 壳(`electron/main.cjs`)通过 IPC 暴露文件操作,并用自定义 `mxfile://` 协议流式供给视频/音频(拖进度条秒切,不占内存);浏览器壳用 File System Access API + 授权句柄持久化。两形态共用同一份渲染层代码。

## 已知限制

桌面版:视频能否播放取决于内置 Chromium 解码器(H.264 / VP9 / AV1 ✅,HEVC 需系统解码器,avi / wmv 不支持);旧版 .doc / .xls 与 PowerPoint 不支持预览;Excel 保存会丢失单元格样式与公式(SheetJS 重写);安装包未签名,首次运行可能触发 SmartScreen 提示(点"仍要运行"即可)。

浏览器版额外限制:无法凭路径字符串直接进入未授权目录;文件夹重命名 = 重建 + 逐个迁移(大目录较慢),跨根移动 = 复制 + 删除;HEVC 需系统支持;无实时文件变更监听(用 F5 刷新)。

## 内存与性能

「⋯ → 内存占用诊断」可实时查看渲染进程 JS 堆、主进程内存、缩略图缓存等指标。应用对内存做了三层控制:

1. **虚拟滚动**:文件列表与表格只渲染可视区域(两万行日志实测只挂载 ~60 行)
2. **缩略图 LRU**:最多缓存 500 张,超限自动 revoke 最早的 blob URL
3. **流式媒体**:桌面版视频/音频通过自定义协议按需读取,不整体载入内存

实测(演示模式浏览+编辑场景):渲染进程 JS 堆约 25-40 MB,主进程 RSS 约 60-80 MB,整机各进程合计约 200-300 MB(Electron 常规水平)。
